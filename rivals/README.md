# ライバルズ再現版（`/rivals/`）

かつて配信されていたカードゲーム「ドラゴンクエストライバルズ」（2017年11月2日〜2021年7月5日）の
ルールを再現した、ブラウザだけで動く一人用カードバトル。通信対戦はなく、相手はすべてコンピューター。

**再現の狙いはサービス終了時点の版**、つまり2020年8月13日のリニューアル後の
『ドラゴンクエストライバルズ エース』。初期版にはなかった**英雄（ヒーローカード）**・
**ダンジョン**・**選択**も入れてある。

公開URL: `https://takeom5700.github.io/rivals/`

外部ライブラリなし。画像・音声ファイルなし。
**モンスターの絵も、カードの枠も、宝石も、全部 SVG と CSS で描いている**（`js/art.js`）。
効果音も WebAudio で合成している。素の静的ファイルなので GitHub Pages にそのまま乗る。

## 再現したルール

盤面は **3段（上・中・下）× 2列（前列・後列）＝ 6マス**。ここがこのゲームの肝で、
どこに置くかで攻撃できる／できないが変わる。

| 決まりごと | 内容 |
|---|---|
| ブロック | 同じ段の前列にユニットがいるとき、その後ろの後列ユニットは攻撃できない |
| ウォール | 3段すべてに敵ユニットがいるとき、敵リーダーを攻撃できない |
| におうだち | 前列にいるあいだ、敵はそれしか攻撃できない（後列では効果なし） |
| 貫通 | 攻撃対象の後ろのユニットにもダメージ。そのユニットからの反撃は受けない |
| ステルス | 自身が攻撃するまで、敵の攻撃・効果の対象にならない |

### 英雄（ヒーローカード）— エースの目玉

英雄カードを使うと**共闘**が始まり、**1ターンに1度ヒーロースキル**が使えるようになる
（MPを消費する）。スキルは**使うほどレベルが上がって強くなる**。

たとえば「ロトの血を引く者」（1コスト）は
`たたかう`（1MP・1ダメージ）→ 1回使うと `王女救出`（2MP・2ダメージ）→
3回使うと `竜王一閃`（3MP・4ダメージ）と育つ。デッキに入れていると**必ず初手に来る**。

収録は9人：ロトの血を引く者／アンルシア（中立）、ローレシアの王子（戦士）、
サマルトリアの王子（僧侶）、ムーンブルクの王女（魔法使い）、レックス（武闘家）、
ヤンガス（商人）、ロザリー（魔剣士）、マーニャ（占い師）。

### ダンジョン

場のマスを1つ使って置く。決まった条件を満たすたびに**耐久値**がたまり、
目標に届くと**踏破**して効果が起き、そのまま消える。
ユニットではないので攻撃も反撃もせず、ブロックにもウォールにも数えない。

例：不思議のダンジョン（耐久値5・味方ユニットが場に出るたび+1・踏破でしあわせの箱4/4）、
竜王の城（耐久値4・ターン終了時+1・踏破で竜王8/8貫通）。全8種。

### 選択

使うときに**2つの効果から自分で1つ選ぶ**カード。
占い師のタロット（①②がランダム）と対になる仕組み。全9種。

### テンションリンク

味方がテンションスキルを使ったときに追加効果を出すユニット特性。

そのほか

- リーダーHP 25／デッキ30枚／同名3枚まで（レジェンドは1枚）
- MP上限は毎ターン+1、最大10。消費したMPはターン開始時に全回復
- 先攻は手札3枚、後攻は手札4枚＋テンションゲージ2段階＋「まほうのせいすい」（MP+1）
- 手札上限10枚、山札が尽きたあとは引くたびに増えるダメージ（デッキ切れ）
- テンションを3段階ためるとリーダー固有のテンションスキル（MP消費なし、使うと0に戻る）
- 武器を装備するとリーダー自身が攻撃できる（耐久力を消費、反撃も受ける）

### 7人のリーダーとテンションスキル

| 職業 | リーダー | テンションスキル |
|---|---|---|
| 戦士 | テリー | 稲妻の加護 — このターン中、味方リーダーは攻撃力+3と貫通を得る |
| 魔法使い | ゼシカ | 紅蓮の火球 — 敵ユニット1体に3ダメージ |
| 僧侶 | ククール | いやしの波動 — 味方キャラすべてを3回復 |
| 武闘家 | アリーナ | おてんば姫 — カード1枚と武術カード1枚を引く |
| 商人 | トルネコ | お宝発見 — ランダムな道具カードを3枚手札に加える |
| 魔剣士 | ピサロ | 魔族の騎士 — 3/2のピサロナイトを召喚 |
| 占い師 | ミネア | 水晶占い — デッキから特技カードを1枚引き、コストを-1 |

占い師のタロットは①②のどちらかがランダムで発動する。「銀のタロット」などで
**必中モード**にすると、自分で選べる。

### 原作との違い（正直なところ）

**カードの数値と効果は原作と一致していない。** 実装時、カードデータベースを
載せているサイト（gameconductor.com / appmedia.jp / dqrdb.com / wikiwiki.jp /
公式サイト）はいずれもこの環境からアクセスできず、正確な数値を取得できなかった。
いま入っている数値は、検索結果と記憶から遊べるように組み直したもの。
**カードの実データが手に入れば `cards.js` を置き換えるだけで差し替えられる**
（画面・AI・デッキ編集はカードの中身に依存していない）。


- **カードの数値と効果は再構成**。公開情報と記憶をもとに組み直したもので、
  原作のカードプールとは一致しない。収録は212枚（原作は1000枚超）。
  内訳：ユニット109／特技80／英雄9／ダンジョン8／武器6。
- カード名は原作・ドラクエシリーズのものを使っているが、性能は別物と思ってよい。
- 原作のイラスト・音声・ボイスは一切使っていない。
- ヒーロースキルのレベルアップに必要な回数、ダンジョンの耐久値などは、
  確認できた実例（ロトの血を引く者・不思議のダンジョン・炎のほこら）に合わせつつ、
  残りは遊べるように決めた。
- ソロバトルアドベンチャー（エースの1人用ストーリーモード）は入れていない。
- 調査時、公式サイトと攻略Wikiへの直接アクセスができなかったため、
  テンションスキルなど一部は検索結果の記述に基づく。

## 見た目

**原作は横画面**なので、1280×720 の「ステージ」を作り、画面の大きさに合わせて
まるごと拡大縮小している。どの端末でも配置は変わらない。

```
┌──────────────────────────────────────────────┐
│ ≡ ⚑  [あなた VS 相手]  [ターン終了]   [相手リーダー]│
│                                        HP▓▓▓ 25 │
│        自後列 │ 自前列 ║ 敵前列 │ 敵後列          │
│         ◇       ◇    ║   ◇      ◇             │
│         ◇       ◇    ║   ◇      ◇             │
│         ◇       ◇    ║   ◇      ◇             │
│ [自リーダー]                    [手札（扇状）]    │
│  HP▓▓▓ 25                                      │
└──────────────────────────────────────────────┘
```

- **リーダー**：自分が左下、相手が右上。円形の肖像を金の枠で囲み、
  その外周がテンションの輪（3段階で一周して光る）。HPは緑のバー＋数字。
- **盤面**：4列×3段。左半分が自分（後列・前列）、右半分が相手（前列・後列）。
  空きマスには石枠、前列は一段明るい。全体をゆるく傾けて奥行きを出している。
- **ユニット**：丸いメダル。行動できるユニットは緑の輪が光る。
  左下に金の攻撃力、右下に赤のHP。
- **カード**：左上に青い結晶のコスト、絵、名前の帯、下に攻撃力とHP。
- **手札**：右下に扇状に並び、選ぶと持ち上がる。
- **演出**：攻撃で斬撃、特技で光の爆ぜ、テンションスキル・ダンジョン踏破で画面が光る。
- **縦持ちのとき**：小さく収まるので「横向きにしてください」と案内する。
  端末の回転をロックしている人向けに、盤面ごと90度回すボタンも用意した。

絵は `js/art.js` が描く。**絵柄は全部で47種類**（生き物・人物が31種、紋章などが16種）。
スライム・ドラキー・よろい・ゴーレム・ドラゴン・魔王・騎士・僧侶・商人などを用意し、
カードごとに絵柄と配色（18色）を割り当てている。
呪文は効果の中身（ダメージ・回復・強化・破壊・凍結・MP・ドロー）で紋章を描き分ける。

## ファイル構成

```
rivals/
  index.html          画面の骨組み（タイトル／リーダー選択／バトル／デッキ編集／図鑑／ルール）
  css/style.css       見た目。配色はサイト本体（タケオの縁日）に合わせた
  js/
    cards.js          カード217枚の定義（デッキに入るのは212枚）＋テンションスキル・英雄スキル
    engine.js         ルールの本体。ブロック・ウォール・におうだち・貫通・死亡処理
    ai.js             コンピューター。ビームサーチ＋評価関数
    decks.js          プリセットデッキ15種と、デッキの正当性チェック
    ui.js             バトル画面。操作の可否は engine.legalActions() だけを見る
    builder.js        デッキ編集とカード図鑑
    art.js            モンスター・紋章の絵（SVG）とカードごとの割り当て
    view.js           カード表示の共通部品（宝石・カード枠・吹き出し）
    storage.js        localStorage（自作デッキ・戦績・設定）
    audio.js          効果音（WebAudioで合成）
    rng.js            決定論的乱数。AIが盤面を複製して先読みするため state に載せる
```

### 設計で気をつけたこと

- **状態は素のデータだけ**。関数や DOM 参照を持たないので、`JSON` で丸ごと複製でき、
  AI が「この手を打ったらどうなるか」を本物のエンジンで試せる。
- **画面はルールを持たない**。押せる／押せないは全部 `legalActions()` から引くので、
  画面とルールがずれない。
- 乱数は `state.rng` に載せる。AIの先読みでも再現性がある。

## コンピューター対戦相手

難易度は「読みの深さ」だけでなく **何を理解しているか** で分けている。
ライバルズは前列後列の使い分けが勝敗を分けるゲームなので、そこを分からせるかどうかを
difficulty の軸にした。

| 難易度 | 探索 | 理解していること | わざと間違える確率 |
|---|---|---|---|
| かんたん | 幅1・手順3 | 良い交換だけ。MPも余らせる | 30% |
| ふつう | 幅3・手順7 | 良い交換。前列後列は分からない | 8% |
| むずかしい | 幅8・手順16 | ブロック・ウォール・におうだち。返しの打点も数える | 0% |
| げきむず | 幅14・手順24 | 上に加えて、ターンを終えたあと相手が何をするかまで読む | 0% |

英雄の共闘状態とダンジョンの踏破の近さも評価に入れてある。

タイプは評価の重み。アグロ／ミッドレンジ／コントロール／コンボ／テンポの5種類で、
同じデッキでも動き方が変わる。

### 強さの実測（ミッドレンジ同型・席と先攻後攻を均等にして各200戦）

| 対戦 | 勝率 |
|---|---|
| ふつう vs かんたん | 92% |
| むずかしい vs ふつう | 77% |
| げきむず vs むずかしい | 56% |
| むずかしい vs かんたん | 99% |
| げきむず vs ふつう | 84% |

1手あたりの思考時間は かんたん1ms / ふつう2ms / むずかしい3ms / げきむず20ms 程度。

> げきむずは当初「全6マスを探索する（wide）」設定にしていたが、枝が増えて
> 枝刈りが雑になり、かえって弱くなった。いまは探索を広げる代わりに
> 「相手の返しを読む候補数」を増やしてある。

> 補足：最初の実装では「毎手ごとに読み直す」作りだったため、探索を深くしても
> 強さが変わらなかった（浅い読みでも打ち直せてしまうため）。
> 手順はターンの頭に一度だけ組み立てる作りに変えて、初めて階段になった。

## 動かしかた・テスト

静的ファイルなので、適当なサーバで開けば動く（ES modules を使うため `file://` は不可）。

```bash
python3 -m http.server 8799
# http://127.0.0.1:8799/rivals/
```

リポジトリには npm の設定を置いていない。検証は使い捨てのスクリプトで行った。

- ランダム自己対戦400戦でエンジンの例外を確認（0件）
- AI同士の総当たりで難易度の階段とデッキ勝率を計測
- Playwright（Chromium）で、タイトル→リーダー選択→対戦→決着までを実際に操作

## 既知の傾向

- **先攻・後攻の釣り合いはおおむね取れている**。15デッキのミラー戦（各64戦）で
  先攻の平均勝率は56%。ただしデッキごとの振れ幅は大きく31〜75%（速い形ほど先攻が有利）。
  後攻の補正は原作どおり手札+1枚・テンション2段階・まほうのせいすい。
- **デッキ間には勝率差がある**。15デッキの総当たり（hard同士・各64戦）で 35〜71%。
  速い形（速攻戦士71%・速攻武闘家70%）が強めで、受ける形（ランプ魔剣士35%・回復僧侶36%）が不利。
  カードの数値を何度か調整して差を縮めたが、これ以上は詰めていない。
- 一人用なので、相手の難易度とタイプを選んで釣り合いを取る前提にしている。
