# 無銘 — 映像作品と、その基軸

物語も説明もない映像作品。一つの種（seed）から、5楽章・約7分半が生まれる。
終わると、次の種の作品が始まる。同じものは二度出ない。

**`art/` の中だけで完結している。** 外部ライブラリ・画像・動画・音声ファイルはゼロ。
絵は Canvas に毎フレーム描いていて、音も WebAudio で合成している。

---

## 一、アートの本質は何か

依頼を受けて最初に書いた分析は、**二度とも外れた**。外れた記録を先に置く。
基軸は、外れたところから引き直したものだからだ。

### 一度目の外れ：「崇高」だと思った（2026-09-19）

最初、私は「圧倒する」を**崇高（sublime）**だと読んだ。巨大なもの、
人間の尺度を超えたもの、霧と光。法を「遅さ」「闇」「尺度」で組んだ。

出てきたのは**雲**だった。依頼者の言葉：

> 空に雲があるみたいな雲の映像に見えるし、だとすると何の個性もないじゃないですか。
> スマホを渡された OL とかがラテアートとか雲の写真とかとりあえず撮りがちじゃない、
> それと発想が全然変わらないって感じで全くアートじゃないんですよね。

正しい。崇高は**ロマン主義絵画の型**であって、手垢がついている。
そして「遅さ」を法に書いた時点で、停滞に言い訳を与えていた。

### 二度目の外れ：「非具象」だと思った（2026-09-19）

次に、私は「再現性からの解放」を**具象からの解放**だと読んだ。
何にも見えない形にすれば、読まれて消費されることがない、と。
密度場から発光する物質、傾けた立方格子、純黒の空隙。

出てきたのは**技術のインスタレーション**だった。依頼者の言葉：

> 今のもの（斜めの格子・黒・発光）は、方向として当たっていない。
> 今のは、表現というより技術のインスタレーションという印象が強い。

これも正しい。「何にも見えない」を目指すと、残るのは**手続きの見え方**だけになる。
レイマーチの霧、プロシージャルの格子。見る人が最初に読むのは「これは計算で作った絵だ」で、
それは作品ではなく**技法の展示**である。

### 三度目：対比である

依頼者が言い切った一行が、二度の失敗をどちらも説明している。

> **あらゆる意味でアートの本質はコントラストである。対比である。**

これを受けて、いま私はこう考えている。

**芸術とは、二つのものを一つの枠に入れて、その差で人を殴ることである。**

- 差が無ければ、何も起きない。均一な霧は美しくても何も起こさない（一度目の失敗）
- 差が**技法の中にしか無い**と、鑑賞ではなく感心になる（二度目の失敗）
- 差が大きすぎて繋がりが切れると、ただの散乱になる

だから作品とは、**差を置く場所の設計**である。どこに置けるか：

| 枠 | 対比の例 |
|---|---|
| 同一画面の中 | 巨大な眼と、その下に並ぶ豆粒の人型。原色の地と黒の図 |
| 時間の上 | 0.2秒の断の束のあとに、20秒の静止 |
| 見せる／見せない | 群衆が画面を埋めた次に、何も無い画面 |
| 手つき | 同じ形を、塗りで描くか／線だけで描くか／刻むか |
| 予測と結果 | 拍が立った瞬間に、拍を外す |

そして**違和感**は、対比の一種ではなく、対比の**保証**である。
物理的に正しいだけの絵は、全部が辻褄の合った一枚になり、差が消える。
依頼者の言葉：

> 物理演算とか自然法則とか数学的な物理的な正しさみたいなのだけだと
> 多分アートっぽくないというか人の心が動かない。
> **違和感をどのように適度に作るかっていうことが重要なんですよ。**

だから法の中に「ひとつだけ違うもの」を**必ず入れる**欄を作った（法「異」）。
群れの中に一羽だけ大きい鳥、片方だけ上がった眉、逆向きに落ちる雨。

## 二、基軸（六法）

**根は対比。**下の六つは、対比を機械が測れる形に割ったものでしかない。
**どれも `js/score.js` の `checkWork()` と `tools/measure.mjs` が実際に測る。**
気分では守れないので、落ちたら公開しない。

### 断 — 切る

**溶かさない。** 景（shot）と景のあいだに何も置かない。

一度目・二度目の版は「カット禁止／全パラメータの溶解だけ」を法にしていた。
その結果、依頼者に**三回**「同じ画面が続いていて退屈」と言われた。
グラデーションは、時間の上の対比を消す装置だった。**この法は撤回した。**

- 1分あたり 25〜65 の断（実測）
- 一番長い景 ÷ 一番短い景 が 97〜140 倍（0.17秒 と 21秒 が同居する）
- **冒頭10秒に 12〜28 の断**（ここで見るのをやめられる。最初に打つ）

### 貌 — 名前のある形を置く

眼・群・手・獣・樹・面・波・火・雨・輪・裂・衆。
**どれも名指せる。** 物語は無いが、「何かが居る」ことは分かる。

二度目の版は「形を直接置かない」を法にしていた。これも撤回した。
人の心は、名前の付かないものより、名前の付くものに強く反応する。

- 12 の図を使い、同じ図が全体の 26% を超えない
- 隣り合う景に同じ図を置かない

### 彩 — 原色を跳ばす

混色しない。面で置く。**そして隣の景と必ず跳ばす。**

- 12 組の配色。地・図・差し色・光の4色で1組
- 隣り合う景で、色相か明暗のどちらかが必ず跳ぶ（跳ばない断は断ではない）
- **長い景は、その途中でも色が段で替わる**（9〜18 回／本）。
  長い景がいちばん退屈になるので、ここを溶かさないことが要
- 閃光（頭の2コマだけ反転）は毎秒3回を超えない。これは生理的な安全の線

### 間 — ためる

断だけでは疲れる。**何も起きない時間があって初めて、断が効く。**

- 楽章ごとに 9 秒以上の景を必ず1つ（実測 9〜18 本／作品）
- 楽章ごとに「ほぼ空」の景を1つ

### 異 — 違和感

正しさだけの絵は動かない。**適量だけ間違えておく。**

- 楽章ごとに「ひとつだけ違うもの」を最低2つ
- 塗りかたを3種以上使う（塗る／線だけ／刻む／点で打つ）
- 線は必ず揺れる。毎コマ乱数を変えて沸かせる（＝定規の線を出さない）
- **絵は 8／12／24 コマで打つ。**なめらかに動かすと CG になる

### 種 — 一点ものにしない

同じ種なら必ず同じ作品。`Math.random()` を一度でも呼んだら死ぬ。

- `js/rng.js` と `paint.js` の `nz()` 以外に乱数の出どころを置かない
- 絵は**時刻だけで決まる**（状態を積まない）。どこへ飛んでも同じ絵が出る

## 三、禁（やらないこと）

- **文字を出さない。** 題も字幕もロゴも記号も、画面の中には一つも置かない
- **説明しない。** 意味を言葉で補うなら、映像である必要が無い
- **溶かして転換しない。** 切る（法「断」）
- **なめらかに動かさない。** コマで打つ（法「異」）
- **グラデーションを塗らない。** 面で置く（法「彩」）
- **物語を作らない。** 因果も起承転結も置かない。並べるだけ

### 撤回した禁（過去の版で掲げていたもの）

| 撤回した禁 | なぜ撤回したか |
|---|---|
| カットを作らない | 時間の上の対比が消え、三回「退屈」と言われた |
| 拍を作らない | リズムは体に直接効く。拍を立てて、外すことに使う |
| 形を直接置かない | 手続きしか残らず「技術のインスタレーション」になった |
| 遅くする（間を法の中心にする） | 遅さが停滞の言い訳になった |

## 四、作りかた（コードの構え）

```
js/score.js   譜 — 何を、どの順で、どれだけの長さ。**数だけ**で作る
js/motif.js   図 — 形の語彙（12種）。名前のある形を置く
js/paint.js   手 — 描きかた（揺れる線・面の塗り・刻み・点・粒）と配色
js/film.js    映写 — 譜を時計で引いて1枚にする。美の判断は持たない
js/sound.js   音 — 譜と同じ数から出す。断のたびに和音が段で替わる
js/main.js    進行 — 再生と書き出し
js/rng.js     種
```

守ること：

- **譜（`score.js`）は数だけで作る。** 関数も DOM も入れない。
  「この楽章だけ手で足す」ができない構えにしてあるのが、法を法たらしめている
- **`film.js` に美の判断を置かない。** 置いた瞬間に、譜の外に法ができる
- **乱数は `rng.js` と `paint.js` の `nz()` だけ。**
  `nz()` は必ず `Math.imul` で混ぜる（素朴に掛けると 2^26 あたりで桁が足りず、
  ハッシュが潰れて同じ値ばかり返す。**実際にそれをやって、線の揺れも雨の配置も死んでいた**）
- **枠は 16:9 固定**（`film.js` の `STAGE`）。画面の形に合わせて広げない
- **書き出しに蓄積（モーションブラー）を足さない。**
  コマ打ちの絵にブラーを足すと、早期アニメーションの呼吸が消える

## 五、動かしかた・検証

```bash
# 譜を種500本ぶん六法で検査（「そう書いたか」）
node art/tools/check-axis.mjs 500

# 焼いた絵を測る（「そう見えるか」。断・動・対比・彩・種）
node art/tools/measure.mjs 0

# 下見。12景を1枚に並べて、実測つきで見る
node art/tools/preview.mjs 7
node art/tools/preview.mjs 7 --open      # 冒頭10秒だけ

# 図（motif）を1つずつ確かめる道具（作品ではない）
node art/tools/sheet.mjs
node art/tools/sheet.mjs --m 3           # 獣だけ、時間で並べる

# 静止画を1枚
art/tools/capture.sh out.png 41 1920x1080 0
```

**`check-axis.mjs` は「そう書いたか」しか見られない。**
絵が壁紙になっていないか、切っても絵が変わっていないかは `measure.mjs` が焼いて測る。
**絵を触ったら必ず両方を通すこと。**

### いまの実測（種0）

| | |
|---|---|
| 断をまたぐ変化 | 平均 40%（12% 以上が合格。**大きいほど切れている**） |
| 冒頭10秒 | 18景／断のたびに平均 38% 変わる |
| 長い景の中の動き | 0.5秒で 0.8〜3.7% |
| 1枚の中の色の幅 | 0.58〜0.98 |
| 原色の景 | 100% |
| 種の再現 | 同じ引数でバイト単位一致 |

### 遊びかた（頁を開いたとき）

触れると始まる。操作は画面に出していない（禁「文字を出さない」）。

`1`〜`5` 楽章へ飛ぶ／`space` 止める／`f` 全画面／`m` 消音／
`n` 次の種へ／`h` 数値／`←→` 20秒

## 六、まだやっていないこと

- **図が12種で足りるとは思っていない。** 同じ語彙を使い続ければ、
  いずれ「またこれか」になる。足すのは `motif.js` の末尾だけ
  （並びを変えると過去の種の作品が変わる）
- **音がまだ弱い。** 断に打撃は入ったが、旋律も声も無い
- 楽章の並び（兆→殖→獣→裂→燼）は固定。ここを種で振ると別の構成になる
