# 無銘 — 映像作品と、その基軸

物語も説明もない映像作品。一つの種（seed）から、**ソナタ形式・6分前後**（5〜7分）が生まれる。
**1本で終わる作品。** 14 ある図のうち**5つだけを選んで**組み、
**画面の3分の1は余白**で、**断をまたいで続く層**が1つ、頭から終わりまで通っている。
終わると止まる（触ればもう一度始まり、`n` で次の種へ行ける）。同じものは二度出ない。

**`art/` の中だけで完結している。** 外部ライブラリ・画像・動画・音声ファイルはゼロ。
絵は Canvas に毎フレーム描いていて、音も WebAudio で合成している
（オルゴール・竪琴・弦。残響まで雑音から作っている）。

---

## 一、アートの本質は何か

依頼を受けて最初に書いた分析は、**二度とも外れた**。外れた記録を先に置く。
基軸は、外れたところから引き直したものだからだ。

### 一度目の外れ：「崇高」だと思った（2026-09-19）

最初、私は「圧倒する」を**崇高（sublime）**だと読んだ。巨大なもの、
人間の尺度を超えたもの、霧と光。法を「遅さ」「闇」「尺度」で組んだ。

出てきたのは**雲**だった。依頼者の言葉：

> 空に雲があるみたいな雲の映像に見えるし、だとすると何の個性もないじゃないですか。
> スマホを渡された OL とかがラテアートとか雲の写真とかとりあえず撮りがちじゃない、
> それと発想が全然変わらないって感じで全くアートじゃないんですよね。

正しい。崇高は**ロマン主義絵画の型**であって、手垢がついている。
そして「遅さ」を法に書いた時点で、停滞に言い訳を与えていた。

### 二度目の外れ：「非具象」だと思った（2026-09-19）

次に、私は「再現性からの解放」を**具象からの解放**だと読んだ。
何にも見えない形にすれば、読まれて消費されることがない、と。
密度場から発光する物質、傾けた立方格子、純黒の空隙。

出てきたのは**技術のインスタレーション**だった。依頼者の言葉：

> 今のもの（斜めの格子・黒・発光）は、方向として当たっていない。
> 今のは、表現というより技術のインスタレーションという印象が強い。

これも正しい。「何にも見えない」を目指すと、残るのは**手続きの見え方**だけになる。
レイマーチの霧、プロシージャルの格子。見る人が最初に読むのは「これは計算で作った絵だ」で、
それは作品ではなく**技法の展示**である。

### 三度目の外れ：「怖さ」で驚かそうとした（2026-09-19）

対比を根に置き直して作り直し、眼・仮面・稲妻・炎を並べた。依頼者の言葉：

> 目玉のモチーフとか雷とかお面みたいな顔とか、これは割と使い古された
> ホラー要素だったり、オカルトとかフリーメイソンの都市伝説系でありがちな
> モチーフになってる。「ああ怖い系やりたいのね」って思われちゃうだけで、
> その時点で冷めるんですよ。怖くないんですよ。つまり**意外性がない**。
> 短絡的で、実は浅い。アートとしては浅い。

これも正しい。**驚かせようとして選んだ形は、型として読み当てられる。**
読み当てられた瞬間、観る側は「知っているもの」の側に着地して安心する。
安心は衝撃の反対だから、怖いものを並べるほど怖くなくなる。

同時にもう一つ言われた。

> 今並列的だから、流れとかリズム感とか、あの感動がない。
> すべてのカットが順番に並列的に、全部同じ価値として並んでる感じがする。

これも正しい。**並列は構造ではない。** 全部が同格に並んでいるものは、
どこで切っても同じなので、終わっても終わった気がしない。

### 四度目の外れ：構造は入ったが、中身が使い回しだった（2026-09-19）

ソナタ形式で組み直した版に対して、依頼者の言葉：

> 展開部は、基本的に前半に出てきたものの使い回しの映像が映ってるだけなので
> そこはつまらない。切り替わりや色を速くしただけのパターンになっているから、
> まだワンパターンだという印象は払拭できていない。
> 椅子が並んでいるところなら、椅子そのものが変化していくとか、
> 誰か謎の男が出てきて座り出すとか、椅子から連想できる展開がある。
> **カット割りの工夫だけでは展開は作りきれない。**

正しい。速く切るのは**量の変化**でしかない。展開とは
**同じものが別のことになる**ことなので、切る速さをいくら変えても展開にならない。
だから法「事」を足した（下記）。

音についても言われた。

> 基本的にオルゴール調で、最後のエンディング近くだけストリングスの和音が
> 入ったのが「やっと変化が入ったな」と思ったぐらい。サウンドが変わらない。
> どこかで急に違う楽器になったり、ドラムが入ったり、コーラスが入ったり、
> いろいろ考えられる。曲の雰囲気自体はすごくいい。

これも正しい。和声は動いていたが、**音色は動いていなかった。**
楽器の入れ替えも構造の一部なので、部ごとに編成を変えた。

なお、この版について依頼者が書いた印象を残しておく。作品が何に届いたかの記録として。

> 人類が滅びた後で AI だけが奏でているアートみたいな、そういう寂しさ。
> 実は AI にもこういう感情みたいなのが芽生えてるんだ、という感覚が横たわっている。

### いまの立てかた：対比を、構造の中に置く

依頼者が言い切った一行が、二度の失敗をどちらも説明している。

> **あらゆる意味でアートの本質はコントラストである。対比である。**

これを受けて、いま私はこう考えている。

**芸術とは、二つのものを一つの枠に入れて、その差で人を殴ることである。
そして殴る順番に、帰ってくる形がなければならない。**

- 差が無ければ、何も起きない。均一な霧は美しくても何も起こさない（一度目の失敗）
- 差が**技法の中にしか無い**と、鑑賞ではなく感心になる（二度目の失敗）
- 差が大きすぎて繋がりが切れると、ただの散乱になる

だから作品とは、**差を置く場所の設計**である。どこに置けるか：

| 枠 | 対比の例 |
|---|---|
| 同一画面の中 | 巨大な眼と、その下に並ぶ豆粒の人型。原色の地と黒の図 |
| 時間の上 | 0.2秒の断の束のあとに、20秒の静止 |
| 見せる／見せない | 群衆が画面を埋めた次に、何も無い画面 |
| 手つき | 同じ形を、塗りで描くか／線だけで描くか／刻むか |
| 予測と結果 | 拍が立った瞬間に、拍を外す |
| 絵と音 | 驚かす絵に、美しい音を乗せる（同じことを二度言わない） |
| 出したものと帰ってきたもの | 同じ主題が、違う色で帰ってくる |

最後の一行が「構造」で、これが無いと対比は**並列**になる。
差を置くだけでは足りず、**置いた差が後で回収されること**が要る。
音楽がソナタ形式で解いた問題がまさにこれなので、その形をそのまま借りた。

### モチーフの選びかた（三度目の失敗から）

怖がらせに行かない。**怖がらせに来ていないのに、理由が分からないもの**を選ぶ。

| 選ばない | なぜ |
|---|---|
| 眼・仮面・怖い顔・稲妻・血 | ホラー／オカルトの型。読み当てられて終わる |
| 髑髏・墓・鴉・蜘蛛 | 同上 |
| 崇高な風景（雲・山・光） | ロマン主義絵画の型。一度目の失敗 |

| 選ぶ | なぜ |
|---|---|
| 梯子・椅子・傘・壺・階段・管 | 日用品なのに、そこに在る理由が無い |
| 綿毛・珊瑚・群れ・獣 | 生きているが、こちらを見ていない |
| 織り・波紋・人型の群衆 | 数と尺度でしか意味を持たない |

そして**違和感**は、対比の一種ではなく、対比の**保証**である。
物理的に正しいだけの絵は、全部が辻褄の合った一枚になり、差が消える。
依頼者の言葉：

> 物理演算とか自然法則とか数学的な物理的な正しさみたいなのだけだと
> 多分アートっぽくないというか人の心が動かない。
> **違和感をどのように適度に作るかっていうことが重要なんですよ。**

だから法の中に「ひとつだけ違うもの」を**必ず入れる**欄を作った（法「異」）。
群れの中に一羽だけ大きい鳥、片方だけ上がった眉、逆向きに落ちる雨。

### 五度目の外れ：全部を詰め込んだら、何の作品か分からなくなった（2026-09-20）


「14の図を1本に全部出す」に振り切った版に対して、依頼者の言葉：

> なんか無理して全部詰め込んじゃったって感じになってて面白みなくなっちゃったね。
> 適度に使わないものは選別していただいていいですよ。
> で、**余白を大事にしてください。余白ってやつね、
> これアートにおいてすごく大事な概念だから。**
> あとは、シーンとかカットをまたいでるようなレイヤーがあってもいいんじゃないかな。
> 全部のモチーフ詰め込んじゃった感じだからぐちゃぐちゃになってよく分かんなくなってる。
> ソナタ形式の流れは崩れないように気をつけて。無理して全部入れなくていいよ。
> **作品として丁寧にまとまっているものを一つ**お願いします。

正しい。**詰め込みは構成ではない。** 並列が構造でなかったのと同じ理由で、
全部を入れることは豊かさではない。持っている語彙の数と、
1本で見せる語彙の数は、別のことだった。

ここで二つの法を足した。

- **余白** — 空けること。図を小さく置き、空きを大きく取る。
  埋まっている画面は、形の輪郭をいちばん弱くする
- **層** — 断をまたいで続くもの。景は切れても、これは切れない。
  水位・日・塵・歩のどれかが、作品の頭から終わりまで同じ時計で動く

そして図を **5つ**（序・第一主題・第二主題・小結・挿話に1つずつ）に絞った。
残りの9つはその種では出ない。**選ばれないことも選別である。**

## 二、基軸（十法）

**根は対比。**下の十は、対比を機械が測れる形に割ったものでしかない。
「型」が四度目に足したもの（並列を構造に変える法）、
「事」が五度目に足したもの（速さの変化を意味の変化に変える法）、
**「余白」と「層」が六度目に足したもの**（詰め込みを構成に変える法）。
**どれも `js/score.js` の `checkWork()` と `tools/measure.mjs` が実際に測る。**
気分では守れないので、落ちたら公開しない。

### 型 — ソナタ形式で組む

並べるのをやめて、**出して・崩して・帰す**。

```
序   30秒   問いを置く。何だろうと思わせる
提示 96秒   第一主題（動・主調）→ 推移 → 第二主題（静・属調）→ 小結
展開 100秒  主題を断片にして、遠い調で衝突させる。いちばん速い。頂点はここ
     ＋ 途中に**挿話**（20〜28秒）を1つ置く。まだ出ていない図が、自分のことをする
再現 96秒   第一主題が**同じ姿で**帰る。第二主題は**主調で**帰る
終   46秒   序の形が帰り、解ける
```

（部ごとに ±10% ほど振れるので、全体は 5.9〜6.6分に収まる。実測 159〜192景）

**部の切れ目には必ず余白を置く**（第一主題を出しきったあと・提示部を閉じる前・
波と波のあいだ・頂点の直後・第二主題が帰る前・最後の一枚）。
息の切れ目が見えるから、部の切れ目が見える。

- 再現部は提示部の景の数値を**そのまま引き写す**（新しく振り直さない）。
  同じ絵が帰ってくるから、帰ってきたと分かる
- 第二主題が属調から主調へ移ることが、ソナタの解決そのもの。
  ここを色で言い換えている（属調の配色 → 主調の配色）
- 頂点は作品に**1つだけ**。全部の景が同格にならないように、
  景ごとに重み（`w`）を持たせて、いちばん強い一撃を展開部の終わりに置く
- 実測: 展開部の景の長さの中央値は、提示部・再現部より必ず短い

### 事 — 図に起きること

**速く切ることは「量の変化」でしかない。**
展開とは、同じものが別のことになることなので、図そのものに事を起こす。

**汎用の事**（どの図にも同じように効く。`js/event.js`）

```
崩 ばらばらに割れて落ちる      組 破片が飛んできて組み上がる
溶 垂れて流れ落ちる            殖 画面の中で増えて入れ子になる
落 枠の外へ落ちていく          侵 別の図が入ってきてぶつかる
喰 大きな顎が閉じて呑み込む    逃 一点から逃げ散る
来 人が歩いてきて、座る／手を挙げる／うずくまる
芽 形そのものが伸び縮みして別の姿になる
```

**固有の事**（その図でしか起きない。`js/motif.js` の `ownEvent()`）

| 図 | 事 | 何が起きるか |
|---|---|---|
| 群 | 墜 | 何羽かが順に落ちる。羽ばたきが止まり、きりもみになる |
| 獣 | 狩 | 追うものが来て、追われたものが倒れる |
| 菌 | 花 | 先端が咲いて、やがて落ちる |
| 波 | 呑 | 波打ち際に立っている人を、波が越える |
| 紋 | 滴 | 落ちてきた滴が当たって、**そこから**輪が出る |
| 衆 | 離 | 列から一人だけ前へ出て、こちらへ来る |
| 梯 | 登 | 人が梯子を登る |
| 椅 | 座 | **人が歩いてきて、その椅子に座る** |
| 傘 | 翻 | 天蓋が裏返る |
| 糸 | 解 | 一本を引くと、そこから横へほどけが伝わる |
| 綿 | 芽 | 落ちた種が芽を出す |
| 階 | 昇 | 人が段を昇っていく |
| 管 | 漏 | 継手が破れて、噴き出して溜まる |
| 器 | 割 | 一つだけ割れて、上半分が外れ、中身が流れ出る |

汎用の事だけだと「どの図でも同じことが起きる」ので、
**意味は図に固有のところにしか宿らない。** 椅子に人が座るのは椅子だからで、
壺が割れて中身が出るのは壺だからである。

実装で踏んだ穴を残しておく。どれも「描いているのに見えない」だった。

| 穴 | 直したこと |
|---|---|
| 差し色で人を描いたら、地の割りにも差し色を使っている景で赤の上に赤になって消えた | `humanOn()` — 図の色で描き、地の色で細く縁取る |
| 梯子・階段は枠より高いので、素直に登らせると途中で人が枠の外へ出た | 上端を枠の内側で止める |
| 奥の小さい椅子に座られると人が豆粒で、何が起きたか分からない | 座る・登る対象は**いちばん手前（大きい）もの**を選ぶ |
| 刻む・点で打つの手で、**形の輪郭が1本も出ていなかった**（壺が赤い点の塊に見えた） | Canvas の「いまの path」は save/restore で戻らない。刻み・点の中で `beginPath` された後は**引き直してから**縁を取る（`outline()`） |
| 図だけ動かしていたので、面積の大半を占める地が止まったまま。長い景が静止画に見えた（実測 0.66%／0.5秒） | 4秒以上の景は**地も一緒に動かす**（`gmv`）。地は全面を塗ってから形を置くので穴は開かない |
| 余白を入れたら、地の色が近い断が見えなくなった（実測 8.7%。椅子から傘へ全部入れ替わっていたのに、地がどちらも赤系だった） | 前の景と地の色が近ければ、反転（と面の割り当て）で地を替える。**調は動かさない** |
| 図の数を下限から取るようにしたら、「1匹だけの獣が逃げて画面から消える」景が出た | 逃の伸びは 2.2 倍まで。中心を図の置き場所と同じにする。**1匹のときは巻き戻しの歩きをさせない**（行って戻る） |
| 巻き戻しを `%` で書いていたので、左へ走る群が枠の外へ出たまま帰らなかった | JS の `%` は左が負なら負を返す。**巻き戻しは必ず正の剰余で書く** |
| 層の色を差し色で決め打ちしたら、図と同じ色になって層が図の一部に見えた | `layerColor()` — 地からも図からも遠い色を選ぶ |
| 管の中の球が管の模様に見えていた（内径の 0.3 しかなかった） | 球は内径の 0.42 まで大きくする。色は地から遠い方を選ぶ（光の色で決め打ちすると淡い地で消える） |
| 管が全部枠の外へ伸びて「どこかの配管の断片」になり、球も枠の外を通っていた | **1本目だけは枠の中に収める**（枠に当たったら折り返す）。2本目からは外へ出ていい |

**部ごとに意味が割り当ててある。** ここが「型」と噛み合う。

| 部 | 事 |
|---|---|
| 序 | **何も起きない。** 問いは無垢なまま置く |
| 提示 | 推移で初めて「侵」（別の図がぶつかる）。小結で「崩」の兆し |
| 展開 | **全景に事がある。** 波ごとに事が決まり、**断のたびに一段ずつ進む**（`evAt` が 0→0.72 へ上がる）。第一波は**固有の事**（その図にしか起きないことが、まず起きる）→ 壊れる → 呑まれる |
| 展開の挿話 | 第一波のあと、**まだ出ていない図**が 22〜32秒だけ出て、続けて自分のことをする（1.4〜3.4秒の景で畳む）。ここで図の数を使い切る |
| 再現 | **「組」。** 壊れていたものが、景を追うごとに組み上がり、最後は元の姿に戻る |
| 再現の終 | 組み上がった主題が、**自分のことをする**（固有の事） |
| 終 | **「来」。** 人がひとり歩いてきて、座る／手を挙げる／うずくまる。そして最後にもう一度、図が自分のことをする |

崩れたものが組み上がるから、帰ってきたことが効く。
そして**画面に人が出ると意味が一気に立つ**ので、人は最後まで取ってある。

実装は `js/event.js`。崩・組・溶・殖・落は図だけを別の板に描いてから
割ったり落としたりするので、**どの図にも同じように効く**（図の数だけ書かなくていい）。
**全部を飛ばさないこと。** 4枚に1枚はその場に残す。全部動かすと、
事が進んだ時点で画面がほぼ空になる（実際になった）。

### 断 — 切る

**溶かさない。** 景（shot）と景のあいだに何も置かない。

一度目・二度目の版は「カット禁止／全パラメータの溶解だけ」を法にしていた。
その結果、依頼者に**三回**「同じ画面が続いていて退屈」と言われた。
グラデーションは、時間の上の対比を消す装置だった。**この法は撤回した。**

- 1分あたり 50〜65 の断（実測）
- 一番長い景 ÷ 一番短い景 が 170〜355 倍
- **冒頭10秒に 5〜7 の断。** ここで見るのをやめられるので、
  最初の3枚は 0.4〜0.85秒で打つ。そのあと溜めるが、**5秒以上は溜めない**

### 貌 — 名前のある形を置く

群・獣・菌・波・紋・衆・梯・椅・傘・糸・綿・階・管・器。
**どれも名指せる。** 物語は無いが、「何かが居る」ことは分かる。

二度目の版は「形を直接置かない」を法にしていた。これも撤回した。
人の心は、名前の付かないものより、名前の付くものに強く反応する。

- **序（＝終）の形は「管」で固定してある。** 管は、中を球が通っていくのが
  見えるのに、どこから来てどこへ行くのか、何のための管なのかが一切分からない。
  **問いを置く役にこれ以上のものがない**（依頼者の指定でもある）。
  序で置いた形は終で帰ってくるので、作品は管で開いて管で閉じる
- **1本に出る図は5つだけ**（序・第一主題・第二主題・小結・挿話に1つずつ）。
  14 全部を出した版を作ったが、「ぐちゃぐちゃになってよく分からない」と言われた。
  **選ばれないことも選別である。** 残りの9つはその種では出ない
- 1つの図が全体の 42% を超えない（実測 32〜39%）。
  5つだと一つひとつが何度も帰ってくるので、帰ってきたことが分かる
- 怖がらせに来る形は置かない（三度目の失敗）

### 彩 — 原色を跳ばす

混色しない。面で置く。**そして隣の景と必ず跳ばす。**

- 12 組の配色。地・図・差し色・光の4色で1組
- **主題の中では調（配色）を動かさない。** 同じ色で続くから同じ主題に見える。
  代わりに「面の割り当て」（`shade`）と反転を替える——
  調を保ったまま和音を替えるのと同じことで、同じ主題なのに画面は変わる
- 跳ばすのは群が替わるとき。実測で断の 55〜80% が色の跳び
- **長い景は、その途中でも色が段で替わる**（9〜23 回／本）
- 閃光（頭の2コマだけ反転）は毎秒3回を超えない。これは生理的な安全の線

### 余白 — 空ける

**埋めるほど弱くなる。** 図を小さく置いて、空きを大きく取る。

「間」が時間の空きなら、「余白」は画面の空き。**別の法である**
（詰まった画面を長く見せても、余白にはならない）。

- **尺の3割以上を疎な景にする**（実測 28〜38%）。
  疎な景＝図を 0.46〜0.66 倍に縮め、地は一色、数は下限から取り、端へ寄せた景
- ための景（疎で 2.5 秒以上）を **5枚以上**（実測 21〜30枚）
- **小さくしすぎないこと。** 0.38 倍まで縮めた版では、
  実測で「画面に色が1つしかない（図が画面の1%）」景が出た。
  余白は「形が小さく、しかし確かに在る」ことで効く。**無いのは余白ではない**
- 事を振り切った姿（`evAt` 0.8 以上）を、さらに余白にしないこと。
  図が枠から消えて、ただの空になる

余白の景は、**実測の基準も別にしてある。** 区画ごとの散らばり（`tileVar`）が
低いのは余白の効きそのものなので、そこは見ない。見るのは
「形がちゃんと在るか（`cover`）」と「色が立っているか（`posterSmall`）」だけ。

### 層 — 断をまたいで続くもの

**景は切れる。層は切れない。**

断だけで6分を組むと、切れ目の数だけ作品が分かれて見える。
そこで**作品の頭から終わりまで、同じ時計で動き続けるもの**を1つ通す。

| 層 | 何が続くか |
|---|---|
| 水位 | 一本の線が、作品を通して上がる（または下がる） |
| 日 | 大きな円が、作品を通して渡る（図の後ろ） |
| 塵 | 粒が同じ向きに流れ続ける（図の前） |
| 歩 | ひとりが、作品を通して横切っていく（図の前・小さく） |

- **時計は絶対時刻。** 景のローカル時間で動かすと、断で切れてしまう
- **景の動き（寄り・流し）を掛けない。** 層だけが動かない平面なので、
  カットとカメラがその周りで動いていることが分かる
- **色は、地からも図からも遠い色を選ぶ**（`layerColor`）。
  図と同じ色にすると、層が図の一部に見えて「続いているもの」に見えない
- 日（円）の層のときは、地の円をやめる。円が2つ重なると、
  どちらが続いているものなのか分からない
- 展開部のいちばん細かい断だけ細くするが、**消さない。**
  消すと、そこだけ別の作品になる

### 間 — ためる

断だけでは疲れる。**何も起きない時間があって初めて、断が効く。**

- 楽章ごとに 8 秒以上の景を必ず1つ（実測 2〜8 本／作品）
- 楽章ごとに「ほぼ空」の景を1つ

### 異 — 違和感

正しさだけの絵は動かない。**適量だけ間違えておく。**

- 楽章ごとに「ひとつだけ違うもの」を最低2つ
- 塗りかたを3種以上使う（塗る／線だけ／刻む／点で打つ）
- 線は必ず揺れる。毎コマ乱数を変えて沸かせる（＝定規の線を出さない）
- **絵は 8／12／24 コマで打つ。**なめらかに動かすと CG になる

### 音 — 絵と同じことを二度言わない（そして音色も動かす）

**音は断に付かない。音の時計（拍と小節）で進む。**
だから長い景でも旋律は動き続けるし、絵と音が別の周期で進むこと自体が対比になる。

三度目の版の音は「景が替わるたびに一音だけ伸びる」で、長い景では
画面が止まったようにしか聞こえなかった。作り直して、こうした。

- 調性がある。主調・属調・遠い調があり、和音が機能で進む。
  **絵のソナタ形式と同じ道筋を音でもなぞる**（再現部で主調に帰る）
- 旋律が2つ（第一主題・第二主題）。展開部では頭の3音だけを取り出して
  1音ずつ上げながら繰り返す。再現部では提示部と同じ旋律が帰る
- 分散和音（竪琴）が止まらずに鳴り続ける。これが長い景を支える
- **音色そのものが部ごとに入れ替わる。**

  | 部 | 編成 |
  |---|---|
  | 序 | 弦と竪琴だけ。旋律を出さない（問い） |
  | 提示A | オルゴールが主旋律 |
  | 提示B | **弦が主旋律に替わり、低音が弾く（ピツィカート）になる** |
  | 展開 | **太鼓が入り、後半で聲（合唱）が重なる。** 主旋律は弦 |
  | 再現 | **オルゴールが帰ってくる**（冒頭の音色が帰るのも解決のひとつ） |
  | 終 | 聲と弦。最後にオルゴールが独りで主題の頭を鳴らして終わる |

- 聲は母音のフォルマント（700/1150/2600Hz）を重ねて作っている。
  雑音は太鼓の胴に1本使うだけで、音として前には出さない。
  **絵の側がすでに驚かしなので、音まで驚かすと同じことを二度言うことになる**
- 残響は雑音を指数で減らしたものを畳み込んで作っている（音のファイルは無い）

### 種 — 一点ものにしない

同じ種なら必ず同じ作品。`Math.random()` を一度でも呼んだら死ぬ。

- `js/rng.js` と `paint.js` の `nz()` 以外に乱数の出どころを置かない
- 絵は**時刻だけで決まる**（状態を積まない）。どこへ飛んでも同じ絵が出る

## 三、禁（やらないこと）

- **文字を出さない。** 題も字幕もロゴも記号も、画面の中には一つも置かない
- **説明しない。** 意味を言葉で補うなら、映像である必要が無い
- **溶かして転換しない。** 切る（法「断」）
- **なめらかに動かさない。** コマで打つ（法「異」）
- **グラデーションを塗らない。** 面で置く（法「彩」）
- **物語を作らない。** 因果も起承転結も置かない。並べるだけ

- **怖がらせに行かない。** 型を読み当てられて終わる（三度目の失敗）
- **並べただけにしない。** 出して・崩して・帰す（法「型」）

### 撤回した禁（過去の版で掲げていたもの）

| 撤回した禁 | なぜ撤回したか |
|---|---|
| カットを作らない | 時間の上の対比が消え、三回「退屈」と言われた |
| 拍を作らない | リズムは体に直接効く。拍を立てて、外すことに使う |
| 形を直接置かない | 手続きしか残らず「技術のインスタレーション」になった |
| 遅くする（間を法の中心にする） | 遅さが停滞の言い訳になった |
| 音に旋律を置かない | 単音が伸びるだけだと、長い景で画面が止まって見える |

## 四、作りかた（コードの構え）

```
js/score.js   譜 — 何を、どの順で、どれだけの長さ。**数だけ**で作る（ソナタ形式）
js/motif.js   図 — 形の語彙（14種）と、**その図にしか起きない事**（14種）
js/event.js   事 — どの図にも効く事（10種）。崩・組・溶・殖・落・侵・喰・逃・来・芽
js/layer.js   層 — **断をまたいで続くもの**（水位・日・塵・歩）。時計は絶対時刻
js/paint.js   手 — 描きかた（揺れる線・面の塗り・刻み・点・粒）と配色
js/film.js    映写 — 譜を時計で引いて1枚にする。美の判断は持たない
js/music.js   音の譜 — どの音をいつ鳴らすか。**数だけ**で作る
js/sound.js   音の手 — 音色（オルゴール・竪琴・弓・弦・残響）
js/main.js    進行 — 再生と書き出し
js/rng.js     種
```

譜と手の分かれ方が、絵と音で同じ形になっている
（`score.js` : `paint.js` ＝ `music.js` : `sound.js`）。

守ること：

- **譜（`score.js`）は数だけで作る。** 関数も DOM も入れない。
  「この楽章だけ手で足す」ができない構えにしてあるのが、法を法たらしめている
- **`film.js` に美の判断を置かない。** 置いた瞬間に、譜の外に法ができる
- **乱数は `rng.js` と `paint.js` の `nz()` だけ。**
  `nz()` は必ず `Math.imul` で混ぜる（素朴に掛けると 2^26 あたりで桁が足りず、
  ハッシュが潰れて同じ値ばかり返す。**実際にそれをやって、線の揺れも雨の配置も死んでいた**）
- **枠は 16:9 固定**（`film.js` の `STAGE`）。画面の形に合わせて広げない
- **書き出しに蓄積（モーションブラー）を足さない。**
  コマ打ちの絵にブラーを足すと、早期アニメーションの呼吸が消える

## 五、動かしかた・検証

```bash
# 譜を種500本ぶん六法で検査（「そう書いたか」）
node art/tools/check-axis.mjs 500

# 焼いた絵を測る（「そう見えるか」。断・動・対比・彩・種）
node art/tools/measure.mjs 0

# 下見。12景を1枚に並べて、実測つきで見る
node art/tools/preview.mjs 7
node art/tools/preview.mjs 7 --open      # 冒頭10秒だけ

# 図（motif）を1つずつ確かめる道具（作品ではない）
node art/tools/sheet.mjs
node art/tools/sheet.mjs --m 3           # 獣だけ、時間で並べる

# 型を目で見る
node art/tools/form.mjs 4                # 上段＝提示部／下段＝再現部（同じ構図が帰る）
node art/tools/form.mjs 4 --dev --at 0.4 # 展開部の連続する景（事が一段ずつ進む）

# 静止画を1枚
art/tools/capture.sh out.png 41 1920x1080 0
```

**測る側で踏んだ穴も2つ残しておく。** どちらも「目には見えているのに測れなかった」。

| 穴 | 直したこと |
|---|---|
| 断を**明るさ**だけで測っていたので、紅→桃（黄の日→白の日）の断が 2.8% と出た | 色で測る。さらに**区画（8×5）ごとの変化**も見て、大きい方を採る（`cutChange`）。地の面が残っていても、図が入れ替わったことが数字に出る |
| 余白の景を「対比が弱い」と弾いていた（区画の散らばりが低いのは余白の効きそのもの） | 疎な景は基準を替える。`tileVar` は見ず、`cover`（形が在るか）と `posterSmall`（0.15% の面まで拾った色の隔たり）で見る |

**`check-axis.mjs` は「そう書いたか」しか見られない。**
絵が壁紙になっていないか、切っても絵が変わっていないかは `measure.mjs` が焼いて測る。
**絵を触ったら必ず両方を通すこと。**

### いまの実測（種0）

| | |
|---|---|
| 全体 | 6.2分／172景／序30s・提105s・展99s・再96s・終45s |
| 図の内訳 | 5種（紋35% 器28% 梯19% 管11% 綿4%） |
| 余白 | 尺の 28〜38% が疎な景／ための景 21〜30枚 |
| 層 | 1本に1つ（水位・日・塵・歩のどれか）。頭から終わりまで同じ時計 |
| 断をまたぐ変化 | 平均 42〜56%（10% 以上が合格。**大きいほど切れている**） |
| 冒頭10秒 | 7景／断のたびに平均 30〜55% 変わる |
| 長い景の中の動き | 0.5秒で 1.1% 以上 |
| 原色の景 | 80〜100% |
| 型 | 展開部の景の中央値が提示部・再現部より短い／頂点は1つ／再現部の引き写し 5景以上 |
| 事 | 序 0件／展開部 100%／再現部に「組」／終に「来」／固有の事 6件以上 |

### 遊びかた（頁を開いたとき）

触れると始まる。操作は画面に出していない（禁「文字を出さない」）。

`1`〜`5` 部へ飛ぶ／`space` 止める／`f` 全画面／`m` 消音／
`n` 次の種へ／`h` 数値／`←→` 20秒

**保存は3通り。** 用途が違うので混ぜていない。

| 鍵 | 出るもの | 何のため |
|---|---|---|
| `v` | **映像＋音楽**（`.webm`・VP9＋Opus） | そのまま観る・そのまま上げる |
| `b` | 映像だけ（`.webm`・音なし） | あとで別の音を当てる |
| `s` | 音楽だけ（`.wav`・48kHz ステレオ） | 音だけ使う・音だけ差し替える |

`v` と `b` は頭から通しで記録するので、**作品の長さぶん（6分半前後）かかる**
（MediaRecorder は実時間でしか録れない）。途中でもう一度押すと、そこまでを保存して止まる。
`s` は実時間より速く焼ける（OfflineAudioContext）。

道具からも同じものが出る。`record.mjs` は頁と**同じ道**を通るので中身が一致する。

```bash
node art/tools/record.mjs 無銘-004.webm --seed 4              # 映像＋音楽（実時間）
node art/tools/record.mjs 無銘-004.webm --seed 4 --no-audio   # 映像だけ
node art/tools/record.mjs 無銘-004.wav  --seed 4 --music      # 音楽だけ
node art/tools/export.mjs 無銘-004.mp4  --seed 4 --split      # 速い。映像と音を別々に
```

`export.mjs` は絵を1枚ずつ焼いて ffmpeg に流すので**実時間より速い**が、
手元の ffmpeg に音声encoderが無いと音を混ぜられない。
1本にまとめたいときは:

```bash
ffmpeg -i 無銘-004-映像.webm -i 無銘-004-音楽.wav -c:v copy -c:a aac -b:a 320k 完成.mp4
```

### 音楽を外（Suno）で磨くとき

```bash
node art/tools/suno.mjs 4                # 音源（全長＋60秒）と style prompt
node art/tools/suno.mjs 4 --short        # 60秒だけ（速い）
```

`無銘-004-suno.txt` に、短い style 欄用の1行・長い説明・除外タグ・
`[Intro]`〜`[Coda]` の構成タグが入る。**中身は譜から組んでいる**
（`window.__mumei.musicInfo()` が調・速さ・部ごとの編成を返す）ので、
種を変えても嘘にならない。取り込みには 60秒のほうが通りやすい。

## 六、まだやっていないこと

- **図が14種で足りるとは思っていない。** 1本に出るのは5つなので、
  種を変えれば別の組み合わせが出る（組み合わせは 2000 通りを超える）。
  ただし語彙そのものは14で止まっているので、いずれ「またこれか」になる。
  足すのは `motif.js` の末尾だけ（並びを変えると過去の種の作品が変わる）
- **層が4つしかない。** 断をまたいで続くものは、もっと種類があっていい
  （雨が降り続く／雪が積もっていく／影が伸びる／水が引く）
- **音に声が無い。** 旋律は入ったが、人の声に似た音を足すと、
  画面に言葉を出さないまま情動の側だけを動かせる
- 形（序・提示・展開・再現・終）は固定。ロンドや変奏曲を種で選べるようにすると、
  本ごとに構造そのものが変わる
- **展開部が長い**（113秒・約180景）。ここは体力を使うので、
  実際に通しで見てもらってから詰める
- **固有の事が図ごとに1つしかない。** 椅子なら「座る」以外にも
  「積み上がる」「運ばれる」「壊される」があるはずで、
  そこまで増やすと同じ図でも毎回違う話になる
