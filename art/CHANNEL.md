# Primaries — チャンネルの設計

YouTube で出し続けるための取り決め。作品そのものの基軸（十法）は
`art/README.md` にある。ここはその**外側**、つまり「どう世に出すか」だけを書く。

出すものは映像ブランドで、コンテンツではない。
**1本 = 1つの世界（1つの種）。** 同じものは二度出ない。

| | |
|---|---|
| チャンネル名 | **Primaries** |
| ハンドル | `@primaries`（取れなければ `@primaries.film`）※空きは各自で確認する |
| 投稿先の決めかた | **鍵（refresh token）の持ち主で決まる。** 許可を出すとき Primaries を選ぶ。`YT_CHANNEL` を入れておけば、違うチャンネルなら上げずに止まる（→ `art/DAILY.md`）|
| 由来 | 原色（primary colours）。混ぜず、面で置く——画面のいちばんの特徴を名詞一語で。**形容詞も用途も入っていない** |
| 作品名 | 1本ごとに変わる（第1作は `Passage`）。チャンネル名は変わらない |
| 動画の題名 | `Passage 004` のように **作品名＋番号だけ** |

**チャンネル名は作品名ではない。** テーマも図も音も毎回変わるが、
**原色・面・コマ打ち・一つの種・十法**は変わらない。変わらない方を名前にしてある。

## 言葉を要らなくする設計

目標は「国境を越えて全世界に届く」こと。訳す必要が無いのではなく、
**訳すものが無い**状態を作る。

| | |
|---|---|
| 画面の中 | 言葉はゼロ。文字・字幕・題字・ロゴ・顔・記号を一つも出さない（基軸の「禁」） |
| 題名 | **題名と番号だけ**。`Passage 004`。数字は唯一の万国共通の表記 |
| 説明欄 | 作品の識別情報だけ。長さ・種の番号。**文章を置かない** |
| 部の名 | 出すなら `I II III IV V`。**日本語の文字を出さない**（作品は日本について何も言っていないのに、漢字が1つ出るだけで「日本のもの」という主題が乗る） |
| サムネイル | 作品のフレームそのもの。文字も矢印も枠も乗せない |
| 検索語（タグ） | ここは裏方で画面に出ないので、各言語の語を入れてよい。唯一の例外 |

説明欄の書式（これ以上書かない）:

```
Generative film. One seed, one world, six minutes.
Made entirely from code — no footage, no images, no stock. Music from the same seed.

Passage 004
I II III IV V
6:00  seed 4
```

**1行目と2行目だけは言葉を置く。** ここは画面の外で、
**機械にどの棚へ置くかを教える唯一の場所**だから（無いと、どこにも置かれない）。
売り文句は入れない——`generative` `film` `code` は**ジャンルの名詞**であって、
`Relaxing` `Beautiful` `4K` のような**主張**ではない。この区別だけは守る。

タグ（画面に出ないので各言語で入れてよい）:

```
generative art, algorithmic art, abstract animation, experimental animation,
visual music, procedural art, creative coding, motion art, flat design animation
```

## 商業主義と一線を画すために、具体的にやらないこと

「一線を画す」は気分では守れない。やらないことを名前で書く。
**どれも、やった方が再生数は伸びる。それを承知で捨てる。**

- **サムネイルに文字・矢印・顔・赤丸・枠を乗せない。** 作品の1フレームをそのまま使う
- **題名に形容詞を入れない。**「Relaxing」「Beautiful」「Cinematic」「4K」「Ambient」
  「作業用」「睡眠用」——全部入れない。題名と番号だけ
- **副題を付けない。** 日本語の副題も、英語の説明句も付けない。
  付けた瞬間に、読む人によって別の作品になる（題名は主題を入れられる唯一の場所）
- **冒頭の挨拶・チャンネル紹介・登録依頼を入れない。** 作品は黒から始まって黒へ帰る
- **用途を売らない。**「10時間」「勉強用BGM」にした瞬間、作品は家具になる
- **Shorts のために切り刻まない。** 60秒に詰めると「間」が壊れ、縦に切ると「枠」が壊れる。
  別surfaceに出したいなら**静止画**を使う（それは作品の一部を正しく写している）
- **速い断の束だけを切り出して煽らない。** 断は「間」があって初めて効く。
  いちばん派手な12秒を抜くのは、作品ではなく広告を作る作業になる
- **音楽を主役にしない。** 主役になった時点でBGMチャンネルになる
- **コメント欄で意味を説明しない。** 説明できるものは、説明で置き換えられる（基軸「一」の裏返し）

見つけてもらう努力を放棄するわけではない。裏方（タグ・再生リスト・
公開時刻）は整える。**画面の中と題名だけは売らない**、という線の引き方をする。

## 1本を出す手順

```bash
# 1. 下見。見ていない世界を公開しない
node art/tools/preview.mjs 12

# 2. 納得したら書き出す（1440p / 24fps / 音つき）
node art/tools/export.mjs Passage-012.mp4 --seed 12

# 3. サムネイルはいちばん強い瞬間を1枚（展開部の頂点あたり）
art/tools/capture.sh Passage-012-thumb.png 185 2560x1440 12
```

下見は絵と一緒に基軸の実測（対比・彩・断・動）を出す。**数値が落ちた種は公開しない。**
種は無限にあるので、落ちたら次の種に行けばいい。
「見ていない世界を出さない」のがこのチャンネルの唯一の編集作業になる。

### 画質（YouTube 向けに分かっていること）

- **1440p 以上で出す。** これは重要で、YouTube は 1440p 以上に明らかに高い
  ビットレートを割り当てる。この作品は暗部の階調が主役なので、
  1080p だと暗いところに帯（バンディング）が出る。`--size 2560x1440` が既定
- **粒（grain）を切らない。** 微細な雑音が階調の帯を防いでいる
- **24fps でよい。** 視点が遅いので 60fps にする意味がない
- 6分・1440p・24fps で、H.264 crf16 だとおよそ 0.9〜1.6GB
- 原色の面が広いので、**色帯（バンディング）より輪郭のブロックノイズが出やすい。**
  crf は 16 より上げないこと

### 書き出しにかかる時間

**速い。** 絵は Canvas に描いているだけなので、1枚あたり十数ミリ秒で焼ける
（960×540 で 576枚がおよそ10秒）。GPU は要らない。
体積レイマーチだった版は1枚 3〜30秒かかっていて、通しでは焼けなかった。

音は解像度に関係なく同じものが出る（`OfflineAudioContext` で焼いている）。
映像だけ後で焼き直しても、音は差し替えなくてよい。

## 音について

いまの音は譜と同じ数から合成した**調性のある音楽**で、
オルゴール・竪琴・弓・弦・太鼓・聲（合唱）と残響でできている（音のファイルは1つも無い）。
絵のソナタ形式と同じ道筋を音でもなぞり、再現部で主調に帰る。
**音色も部ごとに入れ替わる**（提示部の第二主題で弦に替わり、展開部で太鼓と聲が入り、
再現部でオルゴールが帰ってくる）。

**絵と音で同じことを言わない**、という線を引いてある。
絵の側はすでに驚かしなので、音まで驚かすと言葉が重なるだけになる。
だから音は美しい方へ振っている。怖い絵に綺麗な音が乗っている状態そのものが、
このチャンネルのいちばん強い対比になる。

以前は「拍を作らない」「旋律を置かない」を禁にしていたが、**どちらも撤回した。**

自分で作る場合は:

1. `export.mjs --no-audio` で映像だけ焼く
2. 同時に出る `.wav`（合成音）を下敷きに使うか、捨てる
3. 好きな音を当てて、手元の ffmpeg で1本にする

```bash
ffmpeg -i Passage-012.mp4 -i 自作音.wav -c:v copy -c:a aac -b:a 320k -shortest 完成.mp4
```

**音を主役にしないこと**だけが条件。絵が音の伴奏になると、
このチャンネルは音楽チャンネルになる。

## 系譜について（正直な整理）

「ファンタジア」「ファンタスティック・プラネット」を挙げてもらったので、
何を受け継いで何が違うのかを書いておく。**憧れを目標と混同しないため。**

受け継いでいるもの:

- **言葉を使わずに、絵と音だけで全部やる**という構え
- **長い持続**。細かく切らずに、同じものを見続けさせる
- 「ファンタジア」の中でも冒頭の《トッカータとフーガ》の抽象部分に近い。
  つまり系譜としては、むしろ オスカー・フィッシンガー、ジョーダン・ベルソン、
  ジョン・ホイットニー——**抽象映像の系譜**にある

違うもの:

- あの二つは**手で描かれている**。こちらは手で描いた形が一つも無い
  （ただし**手で描いたように見せている**。線は毎コマ揺れ、絵は 8／12／24 コマで打っている）
- あの二つには**キャラクターと筋がある**（ファンタジアの魔法使いの弟子、
  ファンタスティック・プラネットのドラーグ人）。こちらには無い
- あの二つは**音楽が先**にあり、絵が音に付いている。こちらは絵と音が
  同じ種から**別々の時計で**出ている（音は断に付かない。だから長い景でも旋律は動く）

そして「AI だから書き込みが厚い」の中身。**厚みを作っているのは
生成された絵ではない。** 画像生成モデルは1行も使っていない。
厚みの出どころは、**14 の図 × 4 の塗りかた × 12 の配色 × 3 の面の割り当て ×
6 の地 × 数百の景**を、一つの種から組み上げていること。1本に 300〜420 の景が入り、
**14 の図はすべて1本の中に出る。**
同じ景は二度と出ない。人の手なら1本に数ヶ月かかる枚数になる。
——手で描くのでも、生成させるのでもない、第三の作り方になっている。

## 直近の方向（まだやっていない）

1. **図を増やす。** いまは14種（群・獣・菌・波・紋・衆・梯・椅・傘・糸・綿・階・管・器）で、
   1本にはそのうち4つしか使わない。種を重ねれば組み合わせは持つが、
   いずれ「またこれか」になる。足すのは `motif.js` の末尾だけ
2. **事を図ごとに作る。** いまの事（崩・組・喰・来…）はどの図にも同じように効く
   汎用のもの。「椅子に座る」「壺が割れて中身が出る」のような**図に固有の事**を
   足すと、意味の層はもっと厚くなる
3. **形を種で振る。** いまソナタ形式で固定。ロンドや変奏曲を選べるようにすると、
   本ごとに構造そのものが変わる
