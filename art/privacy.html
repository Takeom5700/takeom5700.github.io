プライバシーポリシー — Primaries

Primaries（以下「本アプリ」）は、映像作品チャンネル primaries に作品を投稿するために、 運営者自身が自分のパソコン上で動かす個人用のプログラムです。 一般に配布しておらず、運営者以外の利用者はいません。

1. 本アプリが扱う情報

本アプリは、運営者が Google の同意画面で許可したときに発行される アクセストークン／リフレッシュトークンを、運営者のパソコンの環境変数として そのパソコンの中にのみ保存します。ほかのどこにも送信せず、外部に保存しません。

2. 求めている権限と、その使い道

  • youtube.upload … 生成した映像作品を、運営者自身のチャンネルへ 動画としてアップロードするためにのみ使用します。
  • youtube.readonly … アップロード先が意図したチャンネルかどうかを 確認する（チャンネル名とハンドルを読む）ためにのみ使用します。

これ以外の目的には使用しません。動画の削除・変更、視聴履歴や登録者情報の取得は 行いません。

3. 第三者の情報

本アプリは、運営者以外の個人の情報を一切収集しません。 取得した情報を第三者へ提供・販売することもありません。 広告配信や解析のための情報収集も行いません。

4. 保存期間と削除

トークンは運営者が環境変数を削除した時点で失われます。 アクセスの許可そのものは Google アカウントの「アプリとサービス」 からいつでも取り消せます。

5. Google API サービスユーザーデータポリシー

本アプリによる Google API から取得した情報の使用および他アプリへの転送は、 Google API サービスユーザーデータポリシー （限定的使用の要件を含む）に準拠します。
