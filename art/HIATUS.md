# 休止の記録（2026-09-27）

持ち主の判断で、《primaries》は**ひとまず休止**。毎朝の予定（`Primaries daily`）は
`art\tools\win\uninstall-task.bat` で消してある。動くものは何も残っていない。

依頼者の言葉:
> 「結構いろいろ頑張って伝えたけど、それでも**ワンパターンになってしまっていた**」
> 「これだと**すぐに収益化するぐらいの勢いが出にくそう**だなという理由があるので一旦やめます」
> 「まあ、アートは好きなんで、しかも結構**個人的には面白かった**と思いますよ」

**中止ではない。** 再開したときに同じ壁へ真っ直ぐ突っ込まないように、
ここに「何をやったか」ではなく「**何を間違えたか**」を書く。

---

## 一番大事なこと — なぜワンパターンのままだったのか

道具の上では、毎回ちゃんと違っていた。最後に測った数字はこうだった。

| | |
|---|---|
| 図の組・寸法 | 40通り / 40 |
| 和音の進行・伴奏・旋律・音色 | それぞれ 40通り / 40（音色は3000回組んで3000通り）|
| 調・拍子・作法 | 使える選択肢を全部使い切っている |
| **全部まとめて同じ組み合わせ** | **0件** |

**それでも「ワンパターン」と言われた。この落差が全部である。**

理由は5つある。どれも、真面目にやったことが原因になっている。

### 1. 測っていたのは「引数」で、「印象」ではなかった

`variety.mjs` は**素性の値が違うか**を数えていた。人が見ているのはそこではない。
人は**文法**を見ている。配色が全部違っても、毎回

- ソナタ形式（序→提示→展開→再現→終）
- 図は5つ、原色の面、コマ打ち、16:9
- 断をまたぐ層が1つ
- 部ごとにキーカットが1つ
- 最後は主調へ帰って解決する

これが**1本の例外もなく同じ**なら、人には「同じもの」に見える。
**素性を全部振っても、骨格が同じなら同じに見える。** ここを測る道具は最後まで無かった。

### 2. 変わらない側を守りすぎて、変えられる側しか触っていない

「変えないのは根底の哲学だけ」という線を引いて、そこから
**十法 → 十一法 → 十四法**へ増やした。法を足すたびに**作れる作品の幅は狭くなる。**
失敗するたびに法を足したので、**ワンパターンを直そうとする作業が、
そのままワンパターンを強めていた。**

しかも依頼者は途中で **「ソナタ形式ですら絶対ではないよ」** と言っている。
**構造を変えていい、という許可が出ていたのに、最後まで全作品がソナタ形式だった。**
印象を一番大きく変えられる唯一のつまみを、一度も回していない。**これが最大の見落とし。**

### 3. 検査が作品を一箇所へ寄せていた

`check-axis` / `measure` / `variety` を全部通すことを条件にしていた。
あの3つは**「いまの美意識」を法の形にしたもの**なので、
全部満たす作品＝**様式空間のたった1点**に決まってしまう。
落ちるたびに種を替えるのではなく素材を足したのは正しかったが、
**そもそも「全部通ること」を条件にしたのが、多様性の上限を決めていた。**

### 4. 記事の影響が、思っていたより小さかった

`brief.js` は記事を読んで要素を決めていたが、決めていたのは
**「17ある骨格のうちどの5つを出すか」**であって、器そのものではない。
だから**悲しみの記事も通勤の記事も、原色の面でソナタ形式の5図**になる。
入力の効きしろが、不変の側に比べて圧倒的に小さかった。

### 5. 毎日1本・自動・無選別

`art/CHANNEL.md` に **「見ていない世界を出さない」** と書いてあるのに、
毎朝6時に機械が勝手に焼いて上げる作りにした時点で、**構造的に「見ていない」。**
選別の無い量産は、その生成器の平均へ必ず寄る。

## 再開するなら、順番はこう

**素材を足す作業から始めないこと。** そこは十分ある（実測 314本/400が素材無衝突）。
効かないところを厚くしても、同じ壁に当たる。

| 順 | やること | なぜ |
|---|---|---|
| 1 | **型を複数持つ。** ソナタ／ロンド／変奏／**1カットだけの9分**／800断の作品 | 印象を決めているのは型。ここを振らない限り何をしても同じに見える |
| 2 | **1本ごとに法を選ばせる。** 14の法から作品ごとに数個を選び、**1つは意図的に破る** | 層の無い作品・キーカットの無い作品・解決しない作品があってよい |
| 3 | **「作品どうしがどれだけ違うか」を焼いた絵と音で測る** | 素性の一覧を比べるのをやめる。2本を焼いて縮小して比べる。**これが無かったのが根本** |
| 4 | **記事に器そのものを選ばせる** | 繰り返しの記事からは構造が繰り返しの作品が出るべき |
| 5 | **1日1本をやめる。** 出す前に人が1回見る（週1でよい） | 選別が無いと平均へ落ちる。頻度より選別 |

**逆に、もうやらなくていいこと**: 図を足す・音色を足す・配色を増やす・法を足す。
どれも真面目にやったが、**ワンパターンには効かなかった**（この記録がその証拠）。

---

## 収益について、正直なところ

無言の抽象映像を1日1本は、**作品の質と関係なく**収益化までが遠い。
掴みが無く、検索語も弱く、切り抜きもしない方針にしていた（それ自体は正しい判断だった）。
再開するなら、**作品の線を曲げて売りに行く**か、**売る前提を外して作り続ける**か、
**どちらかを先に決める**こと。両方を同時に満たす設計は、今回うまくいかなかった。
