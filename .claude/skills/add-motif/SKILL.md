# 図（モチーフ）を足す

図は**名前のある形**であること。「群・獣・菌・波・紋・衆・梯・椅・傘・糸・綿・階・管・器」——
どれも名指せる。物語は無いが「何かが居る」ことは分かる。

**抽象の模様を足さない。** 名前が付かないものは、手続きの展示にしか見えない（二度目の失敗）。
**怖がらせに行く形を足さない**（眼・仮面・稲妻・髑髏）。型を読み当てられて終わる（三度目の失敗）。

## 足しかた（順番を守る）

1. `art/js/motif.js` に描く関数を書く（`function newThing(ctx, S, E)`）
2. **`MOTIFS` と `NAMES` の末尾に足す。** 並びを変えると過去の種の作品が変わる
3. 固有の事を `ownEvent()` に足し、`OWN_NAMES` の末尾にも1文字
4. `art/js/score.js` の `COUNT` に `{ 図番号: [下限, 上限] }` を1行
5. `MOVING`（動く＝第一主題むき）／`STILL`（静止＝第二主題むき）／
   `ASKING`（問い＝序むき）のどれかに番号を入れる
6. `node art/tools/sheet.mjs --m <番号>` で**1つだけ描いて確かめる**

## 描くときの決まり

- 線は必ず揺れる（`wob` / `brush`）。`ctx.stroke()` の均一な線は機械の線に見える
- 乱数は `nz()` だけ。**`Math.imul` で混ぜる**（素朴な掛け算は 2^26 で潰れる）
- 面で塗る。グラデーションを使わない
- 位置は `E.sh.ox` / `E.sh.oy` を効かせる（景ごとに置き場所が変わる）
- **時刻は `E.f / E.fps`（コマ）で進める。** `E.p`（景の進み）で横位置を決めない

## 実装で踏んだ穴（全部これで画面が空になった）

| 穴 | 直しかた |
|---|---|
| 巻き戻しを `%` で書いた | JS の `%` は左が負なら負を返す。**正の剰余で書く**（`((v%m)+m)%m`）|
| 図が1つの景で、巻き戻しの歩きをさせた | 巻き戻しの帯には枠外の余白が入っている。**`n === 1` のときは行って戻る**|
| 図が枠より高い（梯子・階段） | 事の主体の上端を**枠の内側で止める**（`ladderSpot` / `stairSpot`）|
| 図が全部枠の外へ伸びた（管） | **1本目だけは枠の中に収める**（枠に当たったら折り返す）|
| 人を差し色で描いた | 地の割りに差し色を使っている景で消える。**`humanOn()` を使う**（図の色で描き、地の色で縁取る）|
| 中を通る球が小さすぎた | 管の内径の 0.3 では模様に見える。**0.42 まで大きく**、色は地から遠い方を選ぶ |
| 刻む・点で打つの手で輪郭が出ない | Canvas の path は save/restore で戻らない。**引き直してから縁を取る**（`outline()`）|

## 固有の事（`ownEvent`）

**意味は固有のところにしか宿らない。** 椅子に人が座るのは椅子だから、
壺が割れて中身が出るのは壺だから。汎用の事（崩・組・溶…）だけだと
「どの図でも同じことが起きる」ので、図ごとに1つは固有の事を持たせる。

- 図と**同じ座標系で重ねて描く**（`film.js` が motif の直後に `ownEvent` を呼ぶ）
- 位置は `chairSpot` / `ladderSpot` / `pipePath` のような**共有の関数**が
  図と事の両方へ同じ数を返す。**片方だけ直さないこと**
- 座る・登る対象は**いちばん手前（大きい）もの**を選ぶ（奥の豆粒では何も見えない）

## 終わったら

```bash
node art/tools/sheet.mjs --m <番号>    # 図だけを確かめる
node art/tools/check-axis.mjs 400      # 譜が壊れていないか
node art/tools/measure.mjs 0           # 絵が壊れていないか
```
