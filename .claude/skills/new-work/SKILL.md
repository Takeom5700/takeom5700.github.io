# 新作を1本作る

`art/` は**一つの種から6分ちょうど（360秒）のソナタ形式が生まれる**映像作品。
チャンネルは **Primaries**。テーマ・図・音は毎回変わるが、
**原色・面・コマ打ち・一つの種・十法は変わらない。**

## 0. 先に読む（飛ばさない）

| 読むもの | 何が書いてあるか |
|---|---|
| `art/README.md` | 十法（型・事・層・断・貌・彩・余白・間・異・種）と、**五度の失敗の記録** |
| `CLAUDE.md` の「映像作品《Passage》」節 | 触るときの禁と、実装で踏んだ穴の一覧 |
| `art/CHANNEL.md` | 出しかた（題名・説明欄・サムネ・やらないこと） |

**失敗の記録を読まずに手を動かさないこと。** 五回とも、
「自分で書いた法がそのまま退屈の原因になっていた」という同じ倒れかたをしている。

## 1. テーマを決める

新作の「テーマ」とは、**何を見せるかではなく、何が起きるか**である。
第1作 `Passage` は「管の中を球が通っていく」——
どこから来てどこへ行くのか分からないものが、ただ通過する。

決めるのは4つだけ。

1. **題名**（`art/js/score.js` の `TITLE`）。主語のない動作か、物の名前。
   形容詞・主張・主題を入れない。日本語の副題を付けない
2. **序の形**（`OPENING`）。**問いを置く図**。説明が付かないものを選ぶ
3. **足す図**（2〜4個）と、その**固有の事**（→ `add-motif` スキル）
4. **足す層**（0〜1個）。断をまたいで作品を渡り続けるもの（→ `art/js/layer.js`）

**怖がらせに行く形を足さない**（眼・仮面・稲妻・髑髏）。三度目の失敗がこれ。

## 2. 実装する

| 触るもの | 何をするか |
|---|---|
| `art/js/motif.js` | 図を**末尾に足す**（`MOTIFS`/`NAMES`/`OWN_NAMES`）。並びを変えない |
| `art/js/score.js` | `COUNT` に1行、`MOVING`/`STILL`/`ASKING` のどれかに番号、必要なら `OPENING`・`TITLE` |
| `art/js/layer.js` | 層を足すなら末尾に（`LAYER_NAMES`/`LAYER_FRONT`）|
| `art/js/paint.js` | 配色を足すなら `PALETTES` の末尾に（**混色しない4色組**）|

**`film.js` に美の判断を置かない。** 形は `motif.js`、描きかたは `paint.js`、
順番は `score.js`、音色は `sound.js`。この関係を崩した版は全部失敗している。

## 3. 検査する（両方通すまで出さない）

```bash
node art/tools/check-axis.mjs 400     # 譜（そう書いたか）。違反 0 でなければ直す
node art/tools/measure.mjs 0          # 絵（そう見えるか）。種を3〜5個で回す
node art/tools/preview.mjs 4          # 下見。**必ず出てきた画像を自分の目で見る**
```

**`check-axis` だけで通さない。** 譜が正しくても絵が壁紙だったことが実際にある。
**`measure` だけでも通さない。** 数値が通っても、見ると退屈なことがある。
`preview.mjs` が出す1枚を**必ず開いて見る**こと。これが最後の砦。

合格の目安（種0・6分00秒172景）:

| | |
|---|---|
| 断をまたぐ変化 | 平均 40〜56%（10% 以上が合格。色と区画で測る）|
| 長い景の中の動き | 0.5秒で 1.1% 以上 |
| 原色の景 | 80〜100%（65% 以上が合格）|
| 余白 | 尺の 28〜38% が疎な景 |
| 図 | 1本に4〜6種（14全部は入れない）|
| 尺 | 360.000 秒ちょうど |

## 4. 種を選ぶ

**見ていない種を出さない。** `preview.mjs` を10種ほど回して、
自分の目で1本選ぶ。選ぶ基準は「6分間、自分が飽きずに見ていられるか」だけ。

## 5. 焼く（→ `publish` スキル）

```bash
node art/tools/record.mjs out/<題名>-NNN-映像と音楽.webm --seed N --size 854x480 --bitrate 200000 --audio-bitrate 96000
node art/tools/record.mjs out/<題名>-NNN-音楽.wav --seed N --music          # 48kHz ステレオ全長
node art/tools/suno.mjs N --short --dir out                                  # 音を外で磨く用
```

## 絶対にやらないこと

- ❌ 全部の図を詰め込む（五度目の失敗。1本に4〜6種まで）
- ❌ 余白を埋める（図を小さく置く景を尺の3割は残す）
- ❌ 速く切って展開にする（速さは量の変化。図に**事**を起こす）
- ❌ 画面に文字を出す／題名に形容詞を入れる
- ❌ 白に近い地に赤い円を置く（日の丸に読まれる。`checkWork` が見張っている）
- ❌ 検査を通さずに焼く。焼いた絵を見ずに出す
